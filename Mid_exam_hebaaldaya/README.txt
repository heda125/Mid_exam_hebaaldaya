Mid_exam_hebaaldaya - Android Studio project

Requirements:
- Android Studio with Android SDK 35 installed
- JDK 17
- Gradle sync with internet access (dependencies are downloaded from Google Maven / Maven Central)

Open:
1. Extract this ZIP.
2. Android Studio > Open > select the extracted Mid_exam_hebaaldaya folder.
3. Wait for Gradle Sync.
4. Run the app.

Package: com.example.mid_exam_hebaaldaya
Language: Java
Layouts: XML

Implemented:
- Email validation using Android Patterns.EMAIL_ADDRESS
- Password minimum length 6
- Login button enabled only when both inputs are valid
- ModeActivity with First / Second / Third tabs and swipe navigation
- PopupMenu with Light / Night / System theme modes
- Back navigation from Second/Third to First, then to MainActivity
- Up button returns to MainActivity
- Double-back Snackbar exit on MainActivity

Note: This is a clean standalone project assembled from the assignment requirements and the details available in the conversation. Replace/merge it with your existing project only after making a backup.
